Điểm mạnh và cảnh báo

Điểm mạnh

  • PKCE S256 và state riêng mỗi flow.
  • Browser context riêng, retry có chủ đích.
  • Storage lock, backup, verify sau commit.
  • Log máy đọc được và UI polling.

Rủi ro ưu tiên

  • Credential/token plaintext trong file/DB/backup.
  • CORS wildcard trên API local.
  • HTML callback cần escape dữ liệu.
  • UI gửi headless nhưng server ép headed.
