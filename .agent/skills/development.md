# Skill: Phát triển tính năng

**Mục tiêu:** triển khai thay đổi nhỏ, dễ review và bảo toàn hành vi hiện có.

- **Input:** requirements đã được PM duyệt, implementation notes, file liên quan.
- **Thực hiện:** thiết kế tối thiểu; sửa theo trách nhiệm module; xử lý lỗi và trường hợp biên.
- **Output:** code, danh sách file đổi, quyết định kỹ thuật và hướng dẫn chạy.
- **Hoàn thành khi:** code chạy được, không lộ secret, có kiểm tra phù hợp và cập nhật `.manager/implementation.md`.
