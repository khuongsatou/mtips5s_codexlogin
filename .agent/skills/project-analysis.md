# Skill: Phân tích dự án

**Mục tiêu:** hiểu nhanh cấu trúc, luồng chạy và rủi ro trước khi sửa code.

- **Input:** yêu cầu, README, entry point, manifest, test và cây thư mục.
- **Thực hiện:** lập bản đồ module; truy vết input → xử lý → output; phân biệt sự kiện quan sát được và giả định.
- **Output:** phạm vi, file liên quan, phụ thuộc, rủi ro, tiêu chí hoàn thành.
- **Hoàn thành khi:** PM và Agent thống nhất scope, không còn điểm mơ hồ ảnh hưởng triển khai.
