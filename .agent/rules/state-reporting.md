# Rule: Cập nhật state và báo cáo PM

- PM cập nhật `.manager/` sau mỗi task hoặc vòng lặp: tiến độ, quyết định, file đổi, kiểm chứng, blocker và bước tiếp theo.
- Agent không để trạng thái chỉ nằm trong hội thoại; thông tin vận hành phải được ghi vào file state tương ứng.
- Khi chuyển owner hoặc status, ghi ngày và người cập nhật.
