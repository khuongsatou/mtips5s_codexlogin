# Workflow: Phân tích → triển khai

1. Đọc requirements và rules liên quan.
2. Lập implementation notes và xác định file ảnh hưởng.
3. Triển khai thay đổi nguyên tử; áp dụng File Splitting nếu cần.
4. Chạy kiểm tra nhanh, cập nhật `implementation.md` và `iteration_log.md`.

**Gate:** PM duyệt scope; không có secret; diff có thể review.
