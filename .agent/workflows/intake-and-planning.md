# Workflow: Tiếp nhận và lập kế hoạch

1. PM nhận yêu cầu, xác định customer/owner và mục tiêu.
2. Agent phân tích repository và dependency.
3. PM ghi `current_task.md`, `requirements.md`, scope và acceptance criteria.
4. PM chia task, cập nhật status và chốt kế hoạch.

**Output:** task rõ ràng, owner, ETA, tiêu chí Done, rủi ro và bước tiếp theo.
