# Workflow: Review code và thiết kế

1. Agent tự review diff theo scope, security và compatibility.
2. Reviewer kiểm tra logic, lỗi, maintainability, test và tài liệu.
3. PM ghi quyết định: approve, sửa, hoặc cần thêm thông tin.
4. Tác giả xử lý comment và cập nhật evidence.

**Output:** quyết định review và danh sách việc còn lại.
