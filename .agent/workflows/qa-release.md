# Workflow: QA, customer review và release

1. Tester chạy unit/integration/smoke và regression phù hợp.
2. Ghi `test-report.md` với lệnh, kết quả và blocker.
3. Customer Reviewer kiểm tra UI, UX và chức năng; ghi `ux-feedback.md`.
4. PM xử lý feedback, quyết định release/iterate và ghi `final_report.md`.

**Gate:** acceptance criteria đạt hoặc ngoại lệ được PM/customer chấp thuận.
