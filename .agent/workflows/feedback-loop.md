# Workflow: Vòng lặp feedback Codex ↔ Antigravity

1. Ghi feedback mới vào `.feedback/inbox.md` với ID `FB-YYYYMMDD-AREA-001`.
2. Codex đánh giá và phản hồi trong `responses.md`.
3. PM chuyển việc được chấp nhận sang `action-plan.md`, gán owner/ETA.
4. Agent thực hiện, Tester/Customer xác minh; cập nhật status và log.

**Status action plan:** Todo / In Progress / Blocked / Done.
